## Google_palystore_DataAnalysis
Hey there! 👋

With millions of apps out there on our 📱, I was curious to understand what makes an app stand out on the Google Play Store. This project helped me analyze trends in app categories, user engagement, ratings, and install behavior — and how different attributes like price, size, and type influence popularity.

💡 Why I Did This:
1. To explore what drives app popularity and user satisfaction
2. To practice data cleaning, EDA, and visualization on a real-world tech dataset
3. To uncover trends that could help developers or marketers make data-driven decisions

🛠️ What I Did:
1. Performed thorough data cleaning by handling missing values, removing duplicates, and fixing inconsistent data
2. Conducted Exploratory Data Analysis (EDA) to study app distribution across categories, type (Free vs Paid), and size
3. Analyzed patterns in user reviews, ratings, price points, and installations
4. Visualized key metrics like top categories by installs, app size vs rating, and pricing trends
5. Studied how app type and category impact user engagement and installs

📌 Key Takeaways:
1. Free apps dominate the platform but not all have high engagement
2. Games, Communication, and Tools are among the most installed categories
3. App size and ratings showed interesting non-linear trends — bigger doesn’t always mean better!
4. Certain niche categories have higher average ratings despite fewer installs

🧰 Tech Stack:
1. Python (Pandas, NumPy, Matplotlib, Seaborn)
2. Jupyter Notebook for structured exploration

📚 What I Learned:
1. Importance of data consistency and dealing with real-world messiness
2. How to extract insights from multi-variable relationships
3. Enhanced my visual storytelling to communicate patterns and findings clearly
